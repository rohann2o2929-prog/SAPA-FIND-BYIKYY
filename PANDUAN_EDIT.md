# PANDUAN EDIT CEPAT
1. Nama aplikasi dan teks utama: buka `index.html`.
2. Isi layanan, jawaban chatbot, FAQ, dan data demo: buka `app.js`.
3. Warna, ukuran, kartu, dan layout: buka `style.css`.
4. Logo: `assets/logo.png`.
5. Tidak perlu install Node.js, npm, framework, atau database.
6. Untuk mengubah data resmi, cari komentar/teks yang ingin diganti langsung dengan fitur Find di editor.
