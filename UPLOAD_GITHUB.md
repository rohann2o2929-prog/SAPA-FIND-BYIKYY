# Upload ke GitHub dari HP

1. Buat repository kosong/public.
2. Masuk repository → **Add file** → **Upload files**.
3. Pilih semua file/folder hasil ekstrak ZIP.
4. Pastikan `index.html`, `style.css`, `app.js`, folder `data`, `assets`, dan `manifest.json` terlihat di root.
5. Tekan **Commit changes**.
6. Masuk **Settings → Pages**.
7. Pilih **Deploy from a branch** → `main` → `/ (root)` → Save.
8. Tunggu Actions selesai lalu buka URL GitHub Pages.
