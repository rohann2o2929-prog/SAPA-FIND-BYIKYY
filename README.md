# SAPA FIND — BYIKYY
Prototype mobile-first Asisten Informasi Layanan Keimigrasian Imigrasi Selatpanjang.

## Isi
- Beranda / splash screen
- Menu layanan lengkap
- Detail Paspor Baru
- Penggantian Paspor
- Paspor Hilang & Rusak
- Paspor Anak
- Persyaratan + checklist interaktif
- Biaya + kalkulator demo
- Prosedur & waktu
- Lokasi + tombol Google Maps
- Foto & biometrik
- Persiapan perjalanan
- FAQ
- Search
- Chatbot rule-based (tanpa server/API)
- Responsive mobile-first
- Tidak memakai framework atau CDN, sehingga ringan dan mudah di-host GitHub Pages

## Upload GitHub
Upload seluruh isi folder ini ke ROOT repository:
`index.html`, `style.css`, `app.js`, folder `assets/`, dan `README.md`.

Jangan upload folder induk `SAPA-FIND-BYIKYY` sebagai satu folder jika ingin `index.html` langsung terbaca oleh GitHub Pages.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → main → /(root) → Save.

## Catatan penting
Semua nominal, jam layanan, alamat, dan persyaratan di prototype adalah CONTOH/placeholder yang harus disesuaikan dengan data resmi terbaru sebelum dipakai sebagai layanan publik.
